# Barbearia Silva

Site da Barbearia Silva, no Bonfim, em Santa Cruz do Sul (RS).

Arquivo único (`index.html`) com fotos e logo embutidos. Para publicar, ative o GitHub Pages neste repositório (branch `main`, pasta raiz).

A página está marcada como `noindex` enquanto for uma proposta. Antes de publicar como site oficial, remover essa tag e confirmar endereço, telefones e autorização de uso das fotos e avaliações.
